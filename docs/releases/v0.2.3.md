## TOK v0.2.3

## Added

- Release archives now get GitHub Artifact Attestations for build provenance when published from the release workflow.
- `make scale-bench` runs a reproducible local read-path benchmark over a generated SQLite scale fixture.
- Release notes are checked from `docs/releases/<tag>.md` before release asset upload.

## Changed

- Main CI now runs Staticcheck in the backend job, so tagged releases are gated on it through release CI verification.
- Release checklist separates checksum signatures, artifact provenance attestations and SBOM status.
- MCP file budgets now keep `internal/mcpserver/server.go` bounded after the handler/type split.

## Fixed

- Web completion evidence now follows the latest completion cycle instead of letting stale override events shadow newer validation.
- Done tasks remain terminal across storage, service, CLI, MCP and HTTP status paths.
- `task_status` MCP metadata now directs completion callers to `task_done`.
- The v0.2.1 SQLite migration path now has automated regression coverage for legacy done events, override events and default fields.
- Public docs no longer describe older release tags as the current alpha.

## Migration

- No new storage migration is introduced in this release.
- Existing v0.2.1 databases still migrate through the v0.2.2 schema path; that path is now covered by an automated regression test.

## Contract Notes

- CLI: `done` tasks are terminal; use a new task for follow-up work instead of reopening a completed one.
- MCP: `task_status` supports `open`, `in_progress` and `blocked`; use `task_done` for completion.
- HTTP API: completion remains on `POST /api/tasks/{id}/done`; non-terminal status updates cannot reopen completed tasks.

## Validation

- CI: release workflow verifies a successful CI run for the tagged commit before publishing assets.
- Local candidate validation: `go test ./...`, `make staticcheck`, `make quality`, `make scale-bench`, `cd web && pnpm lint`, `cd web && pnpm test`, `cd web && pnpm typecheck`, `cd web && pnpm api:check`, and `cd web && pnpm build`.
- Release assets: release workflow publishes Linux and macOS archives with SHA256SUMS, SHA256SUMS.sigstore.json and GitHub Artifact Attestations.
- SBOM: not included in this alpha.
